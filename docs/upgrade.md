# Upgrade

## 0.1.0

First public release. Install with:

```bash
composer require --dev symfinity/ui-designer:^0.1
```

Requires **symfinity/ui-kernel ^0.3.1**.

Author themes in DTCG (`theme.meta.yaml` + variant files) or import from shadcn registry / W3C / Tokens Studio / Figma token files. There is no import path for legacy preset/tone YAML pack formats.
